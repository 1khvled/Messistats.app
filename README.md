## 🌟 Key Features

* **⚡ Real-Time Career Totals:** Live updated goal and assist tallies across FC Barcelona, PSG, Inter Miami, and Argentina.
* **⚔️ Messi vs Ronaldo Head-to-Head:** Interactive side-by-side comparison spanning club, country, trophies, penalties, and international finals.
* **📅 Deep Chronological Logs:**
  * Goals breakdown by calendar year and season.
  * Milestone logs (100th, 200th, 500th, 800th goal records).
  * Birthday matches and anniversary records.
  * El Clásico & vs Real Madrid records.
* **🏆 Trophies & Records Cabinet:** All 46+ team titles and individual accolades (Ballon d'Or, World Cup Golden Ball, The Best).
* **🌍 Internationalization (i18n):** Multi-language routing for English, Spanish (`/es`), French (`/fr`), and Portuguese (`/pt`).
* **📱 Progressive Performance:** Built on Vite with pure ES6+ modules for near-zero bundle size and instant page loads.

---

## 🛠️ Tech Stack

* **Frontend:** Vite, HTML5, CSS3, ES6+ JavaScript.
* **Deployment & Edge:** Vercel Global Edge Network & Cloudflare Workers for instant geographic caching.
* **Data Pipelines:** Static JSON data pipelines built and verified with Node.js automation scripts.

## 🚀 Local Development

```bash
# Clone the repository
git clone https://github.com/1khvled/messi-stats.git
cd messi-stats

# Install development dependencies
npm install

# Start local development server
npm run dev
```

Visit `http://localhost:5173` to explore locally.
