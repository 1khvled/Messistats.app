# Messi UI Improvements Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship homepage, dashboard/charts, and identity/trust UI upgrades better than the ronaldostats reference while keeping the static zero-request build green.

**Architecture:** Additive-only polish inside `src/app.js` renderers + `src/styles.css`. No new deps, no data edits, no shell restructuring. Each task lands one shippable section verified by build + verify + spot-check.

**Tech Stack:** Vite 6 static, vanilla JS renderer, plain CSS, `messi-data.json` source of truth.

## Global Constraints
- `public/data/messi-data.json` is the ONLY source of truth; totals change BY HAND only, never by automation.
- After ANY data-adjacent touch: calendarYears sum == 927, byCompetition sum == 927 (assert via `npm run verify`).
- Provisional fields (penalties 109 / free kicks 66 / hat-tricks 57 / assists 400 / body splits) always ship with the provisional-until-hand-count caveat.
- Zero third-party requests by default; `src/matchday.js` + `src/ads.js` stay disabled.
- Light editorial paper theme kept; no dark gradients/glassmorphism revert.
- Structure inspiration only from ronaldostats.app; no copied code, images, or text.
